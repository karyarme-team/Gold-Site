# نمونه سایت‌های طلافروشی (Gold-Site)

سه نمونه‌ی آماده‌ی سایت طلافروشی؛ فارسی و راست‌چین، HTML/CSS/JS ساده، بدون نیاز به سرور و بدون CDN (فونت وزیرمتن داخل پروژه است، پس با اینترنت ملی هم کار می‌کند).

| پوشه | سبک | ویژگی‌ها |
|---|---|---|
| `sample-1-luxury/` | لوکس، مشکی-طلایی | تیکر قیمت، کارت قیمت‌ها، کالکشن، ماشین‌حساب، درباره ما، تماس |
| `sample-2-minimal/` | مینیمال، کرم | جدول قیمت، فیلتر دسته‌بندی، ماشین‌حساب، نظرات مشتری |
| `sample-3-shop/` | فروشگاهی | جستجو، فیلتر دسته و وزن، مرتب‌سازی، سبد خرید، ثبت سفارش در واتس‌اپ |

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا:
```bash
python3 -m http.server 8000
```
و بروید به http://localhost:8000

## انتشار روی GitHub Pages
Settings → Pages → Source: `main` / root

## شخصی‌سازی
- **قیمت‌ها:** در `shared/gold.js` بخش `SAMPLE_PRICES`. برای قیمت زنده، `GOLD.priceSource` را به آدرس یک JSON با همان ساختار تنظیم کنید.
- **محصولات:** آرایه `PRODUCTS` در `shared/gold.js`.
- **فرمول قیمت:** تابع `calculate` — طلای خام + اجرت + ۷٪ سود + ۱۰٪ مالیات روی (اجرت + سود).
- **شماره واتس‌اپ / تلفن / آدرس:** داخل `index.html` و `app.js` هر نمونه (`989000000000` را عوض کنید).
- **تصاویر:** آیکون‌های SVG در `shared/img/` جایگزین عکس واقعی محصولات هستند.
